# Frontend F4: worker portal and geotagged photos

Worker: Dashboard (counts and short lists), Tasks (New, My jobs, Overdue, Resolved, All),
Task detail (Start work, then Mark as resolved with an after-fix photo).
Citizen report form: the photo's GPS sets the map pin; photos without GPS are refused.
Needs the backend update civic-backend-F4.zip.

Run:  npm install  then  npm run dev
Check: npm run lint, npm test, npm run build
